# 문명의 간격 (Civilization Gap)

**1/5,000 — 7만 년 전 아프리카에서 시작하는 한 혈통의 기록**

인류 역사를 하나의 사람의 후손으로 통과하는 텍스트 인생 시뮬레이션입니다.

> 7만 년 전 아프리카 대형동물 사냥꾼 5,000명.
> 당신은 그중 한 사람이다.
> 대이동 · 농경혁명 · 국가형성 · 제국 · 산업혁명.
> 그리고 그 사이를 지나가던 전쟁 · 질병 · 기근.
>
> 살아남으면 당신의 이름이 이어지고,
> 죽으면 자녀가 물려받는다. 그러다 혈통이 끊기면 끝이다.
>
> 3,500세대를 지나서야 비로소 이 시대가 옵니다.

## 실행

빌드 도구·의존성 없음. 파일을 브라우저로 여세요.

```bash
open index.html          # macOS
xdg-open index.html      # Linux

```

`file://` 프로토콜에서 바로 동작합니다.

## 게임이 실제로 계산하는 것

### 1. 선택 → 6개 문명 지표

`기술 · 과학 · 통합 · 전쟁 · 신앙 · 예술` (각 0–100)

이 지표는 장식이 아닙니다. **사망 확률을 계산합니다.**

| 지표 | 영향 |
| --- | --- |
| 과학 | 역병·전염병 사망률 감소 |
| 통합 | 기근 사망률 감소 |
| 전쟁 | 전쟁 사망률 증가 |
| 기술 | 기본 위험도 감소 |

즉, 매흔병이 터졌을 때 과학이 높으면 이 혈통의 생존율이 올라갑니다.
반대로 전쟁 지수를 키운 길은 30년 뒤의 손실을 키웁니다.

### 2. 인구 곡선

전역 인구 추정치를 연도에 따라 보간한 곡선(`POP_CURVE`)을 두었습니다.
사망자 수를 해당 연도 인구로 나눠 실제 비율을 냅니다.

고대 세계는 "이 혈통이 사는 지역 인구"로 읽습니다 — 고대 세계 인구는
일관된 추정이 없고, 숫자를 지어내는 것보다 근거 있는 범위를 쓰는 편이 낫습니다.

### 3. 세대 계산

```js
genAt(year) = round((year + 70000) / 20)
```

한 세대 20년. 70,000년 ÷ 20 = 3,500세대, 2026년까지 계산하면 3,601세대.

### 4. 혈통의 유지와 단절

- 막마다 자녀 수(0–5)가 결정됩니다.
- **죽어도 자녀가 있으면** 그 이름이 다음 막을 이어받습니다.
- **자녀가 없으면** 혈통이 끊기고, 새 계통으로 시작합니다.

70,000년을 통과할 동안 평균 1.6회 정도 혈통이 끊깁니다.
끊긴 혈통의 수는 엔딩 화면에 기록됩니다.

## 데이터 출처

`MORTALITY_EVENTS`의 21건(전쟁 8 · 질병 7 · 기근 6)은 인류 3대 사망원
사망자 추정치이며, 모두 **추정 범위(`deathsMin`–`deathsMax`)**입니다.
게임은 이 범위 안에서 무작위 값을 뽑아 사용하므로, 화면에 표시되는
위험도 역시 범위입니다. 단일 숫자가 아닙니다.

연도 파싱이 관용적인 표현(`541-549`, `1492-1600s`, `1981-현재`, `1943`)
을 모두 처리합니다.

## 알려진 한계

- **3대 사망원 데이터가 541년 이후에만 존재합니다.** 10개 시대 중
  1–7시대(70,000년 전 ~ 500년 전, 전체 시간축의 68%)에는 역사적 대재앙
  기록이 하나도 없어 기본 위험도로만 굴러갑니다. 실제 역사의 공백을
  그대로 반영한 것이지만, 그 구간에서는 "3대 사망원"을 체험할 수 없습니다.
- **최종 세대 수는 고정값입니다.** 완주하면 언제나 3,601. 선택은 중간의
  생존 여부와 문명 지표에 영향을 주지만, 최종 세대 수에는 영향을 주지 않습니다.
- **인구와 사망자 수는 모두 추정치입니다.** 위험도 역시 추정 범위이며,
  통계가 아니라 서사입니다.
